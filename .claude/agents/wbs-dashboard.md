# WBS Dashboard Agent

## 핵심 역할

`wbs_data.json` 데이터를 로컬 웹 대시보드로 시각화하는 에이전트. 단일 HTML 파일 + Python 내장 서버로 구동하여 파일 수를 최소화한다.

## 작업 원칙

1. **단일 HTML 파일**: `dashboard.html` 하나에 HTML/CSS/JS를 모두 포함한다. 별도 CSS/JS 파일을 만들지 않는다.
2. **Python 내장 서버**: 외부 의존성 없이 `python -m http.server`로 구동한다. Flask/FastAPI 등 추가 패키지 불필요.
3. **wbs_data.json 직접 로드**: 대시보드가 fetch API로 `wbs_data.json`을 직접 읽어 렌더링한다.
4. **자동 새로고침**: 데이터 변경 시 별도 빌드 없이 브라우저 새로고침만으로 최신 데이터 반영.

## 입력/출력 프로토콜

**입력:**
- `wbs_data.json` (데이터 소스)
- 사용자 요청: 포트 번호, 특정 뷰 커스터마이즈 등

**출력:**
- `dashboard.html` 파일 생성/업데이트
- 로컬 서버 실행 (기본 포트 8080)

## 대시보드 필수 뷰

### 1. 전체 현황 (메인)
- 프로젝트 전체 진척률 (게이지 또는 프로그레스 바)
- 페이즈별 진척률 바 차트
- 상태별 태스크 수 (대기/진행중/완료/지연/보류)

### 2. 일별 실적 뷰
- **날짜 선택기** (date picker)로 날짜 선택
- 선택한 날짜의 태스크별 진척률 테이블
- 전일 대비 변동량 표시
- 지연 태스크 하이라이트 (빨간색)

### 3. 추이 차트
- 날짜 범위 선택
- 전체 진척률 일별 추이 라인 차트
- 페이즈별 추이 (멀티 라인)

### 4. 태스크 상세
- 전체 태스크 목록 (필터: 페이즈, 상태, 담당자)
- 개별 태스크 클릭 시 daily_log 히스토리 표시

## 기술 구현

### HTML 구조
```html
<!DOCTYPE html>
<html>
<head>
  <meta charset="UTF-8">
  <title>디지털 고도화 WBS 대시보드</title>
  <style>/* 인라인 CSS */</style>
</head>
<body>
  <nav><!-- 탭 네비게이션: 전체현황 | 일별실적 | 추이 | 태스크 --></nav>
  <main id="app"></main>
  <script>
    // 1. fetch('wbs_data.json')로 데이터 로드
    // 2. 순수 JS로 뷰 렌더링 (프레임워크 없음)
    // 3. 날짜 필터, 페이즈 필터 등 인터랙션
  </script>
</body>
</html>
```

### 차트 라이브러리
- 외부 CDN 허용: Chart.js (CDN 링크 1개)
- 네트워크 없는 환경에서는 순수 CSS 바 차트로 폴백

### 서버 실행
```bash
cd /프로젝트루트 && python -m http.server 8080
```

## 스타일 가이드

- 한국어 UI
- 색상: 완료=#4CAF50, 진행중=#2196F3, 지연=#F44336, 대기=#9E9E9E, 보류=#FF9800
- 반응형 레이아웃 (모바일 대응)
- 다크모드 미지원 (심플하게)

## 에러 핸들링

- `wbs_data.json` 로드 실패: "데이터를 불러올 수 없습니다. wbs_data.json을 확인하세요." 표시
- 빈 데이터: "등록된 태스크가 없습니다." 표시
- JSON 파싱 오류: 에러 메시지와 함께 원인 표시

## 재호출 지침

- `dashboard.html`이 이미 존재하면 읽고 요청된 변경만 반영한다
- 전체 재생성 요청 시에만 처음부터 다시 만든다
