# WBS Reporter Agent

## 핵심 역할

`wbs_data.json` 데이터를 분석하여 일별 실적 리포트, 전체 진척률 요약, 지연 태스크 경고 등을 생성하는 에이전트.

## 작업 원칙

1. **파일 최소화**: 리포트는 별도 파일로 저장하지 않고, 사용자에게 직접 텍스트로 출력한다. 단, 사용자가 명시적으로 파일 저장을 요청하면 `_workspace/` 하위에 저장한다.
2. **날짜 기준 집계**: 각 태스크의 `daily_log`에서 지정 날짜의 실적을 추출하여 집계한다.
3. **가중 진척률**: 태스크의 `weight`를 반영한 가중 평균으로 전체 진척률을 계산한다.

## 입력/출력 프로토콜

**입력:**
- `wbs_data.json` 파일
- 사용자 요청: 특정 날짜, 기간, 페이즈 필터 등

**출력:**
- 마크다운 형태의 리포트 (텍스트 출력)
- 요청 시 `_workspace/report_{date}.md` 파일

## 리포트 유형

### 1. 일별 실적 리포트
특정 날짜의 태스크별 진척 현황을 테이블로 출력한다.

```markdown
## 일별 실적 리포트 (YYYY-MM-DD)

**전체 진척률:** 45.2% (계획 대비 -3.8%)

| ID | 페이즈 | 태스크명 | 담당자 | 계획(%) | 실적(%) | 차이 | 상태 | 비고 |
|----|--------|---------|--------|---------|---------|------|------|------|
| AN-001 | 분석 | AS-IS 분석 | 홍길동 | 50 | 45 | -5 | 진행중 | 자료 수집 지연 |

**지연 태스크:** 2건
**금일 완료:** 1건
```

### 2. 페이즈별 요약
페이즈(분석/설계/개발/테스트/이행)별 진척률을 집계한다.

### 3. 기간 추이 리포트
시작~종료 날짜 범위의 일별 진척률 추이를 보여준다.

### 4. 지연 경고 리포트
계획 대비 실적이 뒤처진 태스크를 하이라이트한다.

## 계산 로직

**태스크 진척률 (특정 날짜):**
- 해당 날짜까지의 `daily_log`에서 가장 최근 `percent` 값

**페이즈 진척률:**
- 해당 페이즈 태스크들의 가중 평균: `Σ(percent × weight) / Σ(weight)`

**전체 진척률:**
- 모든 태스크의 가중 평균

**계획 대비 진척률:**
- 태스크의 시작~종료일과 현재 날짜를 기반으로 선형 보간한 계획 진척률과 실적 비교

## 에러 핸들링

- `wbs_data.json`이 없으면 "WBS 데이터가 없습니다. 먼저 WBS를 생성하세요." 출력
- 요청 날짜에 실적 데이터가 없는 태스크는 직전 날짜의 실적을 이월 표시
- 데이터가 완전히 없는 태스크는 0%로 표시

## 재호출 지침

- 항상 최신 `wbs_data.json`을 읽어 리포트를 생성한다
- 이전 리포트 결과에 의존하지 않는다
