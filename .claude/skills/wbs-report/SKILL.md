# WBS 리포트 스킬

`wbs_data.json`을 읽어 다양한 형태의 진척률 리포트를 생성한다.

## 리포트 출력 원칙

1. **기본은 텍스트 출력** — 별도 파일을 만들지 않고 마크다운으로 직접 출력한다
2. **파일 저장은 명시적 요청 시에만** — "파일로 저장해줘", "엑셀로 만들어줘" 등 요청 시 `_workspace/`에 저장
3. **날짜 기본값은 오늘** — 날짜를 지정하지 않으면 오늘(현재 날짜) 기준

## 리포트 유형

### 1. 일별 실적 리포트 (가장 빈번)

**트리거:** "오늘 실적", "4/10 실적", "일별 리포트"

```markdown
# 일별 실적 리포트 — 2026-04-10

## 전체 현황
- **전체 진척률:** 45.2% (가중평균)
- **계획 진척률:** 49.0%
- **차이:** -3.8% (지연)
- **금일 변동 태스크:** 5건 | **완료:** 1건 | **지연:** 2건

## 페이즈별 요약
| 페이즈 | 태스크 수 | 가중 진척률 | 계획 대비 |
|--------|----------|-----------|----------|
| 분석 | 8 | 72.5% | +2.5% |
| 설계 | 5 | 30.0% | -5.0% |

## 태스크 상세
| ID | 페이즈 | 태스크명 | 담당자 | 실적(%) | 전일비 | 상태 | 비고 |
|----|--------|---------|--------|---------|--------|------|------|
| AN-001 | 분석 | AS-IS 분석 | 홍길동 | 45 | +15 | 진행중 | 인터뷰 완료 |

## 주의 태스크
- **지연:** DS-002 UI 설계 (계획 40%, 실적 20%, -20%)
- **보류:** DV-003 API 개발 (사유: 외부 API 연동 대기)
```

### 2. 페이즈별 요약 리포트

**트리거:** "페이즈별 현황", "단계별 진척률"

페이즈 단위로 집계. 각 페이즈의 태스크 수, 완료 수, 가중 진척률, 시작/종료 예정일 표시.

### 3. 기간 추이 리포트

**트리거:** "이번 주 추이", "4/1~4/10 추이", "주간 보고"

날짜 범위 내 일별 전체 진척률 변화를 테이블/차트로 표시.

```markdown
## 기간 추이 (2026-04-07 ~ 2026-04-10)
| 날짜 | 전체 진척률 | 전일비 | 변동 태스크 |
|------|-----------|--------|-----------|
| 04-07 | 38.0% | - | 3건 |
| 04-08 | 40.5% | +2.5% | 4건 |
| 04-09 | 42.1% | +1.6% | 2건 |
| 04-10 | 45.2% | +3.1% | 5건 |
```

### 4. 지연 경고 리포트

**트리거:** "지연 태스크", "위험 태스크", "경고"

계획 대비 실적이 10% 이상 뒤처진 태스크를 추출. 지연 일수와 영향 범위를 분석.

### 5. 담당자별 리포트

**트리거:** "담당자별 현황", "홍길동 실적"

특정 담당자 또는 전체 담당자별 태스크 현황을 집계.

## 계산 로직

### 태스크 진척률 (특정 날짜 기준)
1. `daily_log`에서 해당 날짜 이하의 가장 최근 기록의 `percent` 사용
2. 기록이 전혀 없으면 0%

### 가중 진척률
```
Σ(task.percent × task.weight) / Σ(task.weight)
```

### 계획 진척률 (선형 보간)
```
task_plan_percent = min(100, (현재날짜 - start_date) / (end_date - start_date) × plan_percent)
```

### 전일비
```
오늘 진척률 - 어제 진척률
```

## 데이터 없음 처리

- `wbs_data.json` 미존재: "WBS 데이터가 없습니다. 먼저 WBS를 생성해주세요."
- 요청 날짜에 데이터 없음: 가장 최근 데이터 기준으로 이월 표시, "(이월)" 태그 추가
- 태스크에 daily_log 없음: 0%로 표시
